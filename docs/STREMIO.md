# Stremio-compatible addons

Open **Integrations** to connect Jellyfin, Emby, Plex and HTTP Stremio addons. Choose **Add addon** and paste the manifest URL or `stremio://` install link generated by the addon's configuration page. **Add Cinemeta** offers the official movie and series metadata catalog. No addon is installed automatically.

Each profile has its own addons, enabled state and saved title matches. Refresh an addon to update its manifest and cached catalogs, replace its configured install link, or remove it. Configurable addons have an **Open configuration** action. Install links, catalog caches and saved matches use the existing encrypted settings storage; configured URLs are masked in the UI.

## Browse and play

**Movies & series** combines library titles and installed addon catalogs. Its catalog selector retains local provider categories and adds each addon catalog. Select a catalog for genre filters and **Load more** when advertised by the addon. Search looks through searchable addon catalogs as well as the saved library.

Selecting a movie or series opens its details page and a Dracula source picker. Results are grouped by addon alongside the title's original library versions. One unavailable addon does not hide other results. A series offers seasons and an episode selector; changing the episode refreshes sources using its exact video ID. Playback uses NullTV's existing native player and Now Playing view.

Server IMDb identities are used when supplied. An unmatched library title offers catalog matching and a manual IMDb ID field; the selection is saved for that title. Episode lookup uses the series identity with season and episode, rather than an episode's unrelated IMDb ID. Titles without usable episode metadata need a metadata source before addon episode lookup can work.

## Supported protocol

- HTTP(S) JSON manifests and `catalog`, `meta` and `stream` resources; short and per-resource declarations, content types and ID prefixes.
- Configured URL paths and query parameters, catalog search/skip/genre extras and required-extra handling.
- Movie metadata, series videos, specials and opaque episode IDs.
- HTTP(S) direct and debrid stream URLs, request headers (including comma-containing Cookie values), and subtitles supplied with stream results. Captions respect the player's existing Off/Automatic preference.
- External web results open only when selected.

Raw `infoHash` torrent results are identified but **cannot play in this release**. They need a separate torrent streaming component. NullTV does not launch or execute addon JavaScript, import Stremio accounts, query standalone subtitle resources, or implement Stremio's full client/service stack. Addon access and stream availability depend on the chosen service and account configuration.

Resource responses have a 22-second timeout and an 8 MiB limit. Catalog and source requests run with bounded concurrency and cancel when their page or dialog closes. Native playback clears prior request headers before each new stream.

Protocol references: [HTTP protocol](https://stremio.github.io/stremio-addon-sdk/protocol.html), [manifest](https://stremio.github.io/stremio-addon-sdk/api/responses/manifest.html), [metadata](https://stremio.github.io/stremio-addon-sdk/api/responses/meta.html), [streams](https://stremio.github.io/stremio-addon-sdk/api/responses/stream.html).
